# عرض تقديمي - مشروع مصنع الملابس

## نظرة عامة على المشروع

مصنع الملابس هو تطبيق ويب شامل لإدارة مصنع ملابس يقدم خدمات البيع بالتجزئة والتصنيع المخصص. يوفر المشروع منصة متكاملة للعملاء لإدارة طلباتهم ومراقبة حالة التصنيع.

## الميزات الرئيسية

### 🛍️ متجر إلكتروني

- **عرض المنتجات**: عرض جميع المنتجات مع إمكانية الفلترة والبحث
- **صفحة منتج مفردة**: عرض تفاصيل كاملة لكل منتج
- **سلة التسوق**: إدارة المنتجات المختارة قبل الشراء
- **نظام الطلبات**: إتمام عملية الشراء وتتبع الطلبات

### 🏭 طلب التصنيع المخصص

- **نموذج طلب التصنيع**: واجهة سهلة لطلب تصنيع ملابس مخصصة
- **تخصيص المواصفات**: اختيار المقاس، اللون، نوع القماش
- **تتبع حالة الطلب**: مراقبة مراحل التصنيع المختلفة
- **تقدير السعر**: حساب سعر تقديري للطلب

### 👥 نظام المستخدمين

- **تسجيل الدخول**: نظام مصادقة آمن
- **إنشاء حساب**: تسجيل عملاء جدد
- **أدوار المستخدمين**: عميل ومدير
- **إدارة الملف الشخصي**: تحديث المعلومات الشخصية

### 📊 لوحة الإدارة

- **نظرة عامة**: إحصائيات شاملة للمبيعات والطلبات
- **إدارة المنتجات**: إضافة، تعديل، حذف المنتجات
- **إدارة الطلبات**: تتبع وتحديث حالة الطلبات
- **إدارة طلبات التصنيع**: متابعة طلبات التصنيع المخصص

### 📱 تصميم متجاوب

- **دعم جميع الأجهزة**: موبايل، تابلت، ديسكتوب
- **واجهة سهلة الاستخدام**: تصميم بديهي ومريح
- **دعم اللغة العربية**: واجهة باللغة العربية مع دعم RTL

## التقنيات المستخدمة

### Frontend

- **React 19.1.1**: مكتبة واجهة المستخدم
- **TypeScript 4.9.5**: لغة البرمجة مع دعم الأنواع
- **React Router 7.9.1**: إدارة التنقل بين الصفحات
- **Tailwind CSS**: إطار عمل CSS للتصميم
- **Lucide React**: مكتبة الأيقونات
- **React Hook Form**: إدارة النماذج
- **Yup**: التحقق من صحة البيانات

### Backend & Data

- **JSON Server**: خادم API وهمي
- **Axios**: مكتبة HTTP للاتصال بالخادم
- **Concurrently**: تشغيل عدة أوامر في نفس الوقت

### State Management

- **React Context**: إدارة الحالة العامة
- **Local Storage**: حفظ البيانات محلياً

## هيكل المشروع

```
src/
├── components/          # المكونات المشتركة
│   ├── Header.tsx      # شريط التنقل العلوي
│   └── Footer.tsx      # تذييل الصفحة
├── context/            # إدارة الحالة
│   ├── AuthContext.tsx # سياق المصادقة
│   └── CartContext.tsx # سياق سلة التسوق
├── data/               # البيانات
│   └── db.json         # قاعدة البيانات الوهمية
├── pages/              # صفحات التطبيق
│   ├── Home.tsx        # الصفحة الرئيسية
│   ├── Login.tsx       # تسجيل الدخول
│   ├── Register.tsx    # إنشاء حساب
│   ├── Products.tsx    # صفحة المنتجات
│   ├── ProductDetail.tsx # تفاصيل المنتج
│   ├── Cart.tsx        # سلة التسوق
│   ├── ManufacturingOrder.tsx # طلب التصنيع
│   ├── About.tsx       # صفحة عنا
│   ├── Contact.tsx     # صفحة اتصل بنا
│   └── AdminDashboard.tsx # لوحة الإدارة
├── services/           # خدمات API
│   └── api.ts          # دوال الاتصال بالخادم
├── types/              # تعريفات TypeScript
│   └── index.ts        # أنواع البيانات
└── utils/              # أدوات مساعدة
```

## الصفحات المتوفرة

### للزوار (غير المسجلين)

- **الصفحة الرئيسية**: عرض المنتجات الرائجة والمعلومات العامة
- **صفحة المنتجات**: تصفح جميع المنتجات مع إمكانية البحث والفلترة
- **صفحة منتج واحد**: عرض تفاصيل منتج معين
- **صفحة طلب التصنيع**: نموذج طلب تصنيع مخصص
- **صفحة عنا**: معلومات عن الشركة والفريق
- **صفحة اتصل بنا**: نموذج التواصل مع الشركة

### للعملاء المسجلين

- **جميع صفحات الزوار** +
- **سلة التسوق**: إدارة المنتجات المختارة
- **الملف الشخصي**: عرض وتعديل المعلومات الشخصية
- **تتبع الطلبات**: مراقبة حالة الطلبات

### للمديرين

- **جميع صفحات العملاء** +
- **لوحة الإدارة**: إدارة شاملة للنظام
  - نظرة عامة على الإحصائيات
  - إدارة المنتجات (CRUD)
  - إدارة الطلبات
  - إدارة طلبات التصنيع

## قاعدة البيانات

### الجداول الرئيسية

- **products**: بيانات المنتجات

- **حماية الصفحات**: منع الوصول غير المصرح به

- **تحسين الصور**: استخدام صور محسنة للويب

### سهولة الاستخدام

## كيفية التشغيل

### المتطلبات

- Node.js 16 أو أحدث
- npm أو yarn

### خطوات التشغيل

1. **تثبيت التبعيات**:

   ```bash
   npm install
   ```

2. **تشغيل الخادم**:

   ```bash
   npm run dev
   ```

3. **فتح المتصفح**:
   - التطبيق: http://localhost:3000
   - API: http://localhost:3001
