# مصنع الملابس - Clothing Factory

مشروع شامل لإدارة مصنع ملابس يقدم خدمات البيع بالتجزئة والتصنيع المخصص.

## 🚀 الميزات الرئيسية

### 🛍️ متجر إلكتروني

- عرض المنتجات مع إمكانية البحث والفلترة
- صفحة منتج مفردة مع تفاصيل كاملة
- سلة تسوق ذكية
- نظام طلبات متكامل

### 🏭 طلب التصنيع المخصص

- نموذج طلب تصنيع سهل الاستخدام
- تخصيص المواصفات (المقاس، اللون، نوع القماش)
- تتبع حالة الطلب
- تقدير السعر التلقائي

### 👥 نظام المستخدمين

- تسجيل الدخول وإنشاء حساب
- أدوار مختلفة (عميل، مدير)
- إدارة الملف الشخصي

### 📊 لوحة الإدارة

- إحصائيات شاملة
- إدارة المنتجات (CRUD)
- إدارة الطلبات
- إدارة طلبات التصنيع

### 📱 تصميم متجاوب

- يعمل على جميع الأجهزة
- دعم اللغة العربية مع RTL
- واجهة سهلة الاستخدام

## 🛠️ التقنيات المستخدمة

- **Frontend**: React 19.1.1, TypeScript, Tailwind CSS
- **Routing**: React Router 7.9.1
- **State Management**: React Context
- **Forms**: React Hook Form + Yup
- **Icons**: Lucide React
- **Backend**: JSON Server
- **HTTP Client**: Axios

## 📦 التثبيت والتشغيل

### المتطلبات

- Node.js 16 أو أحدث
- npm أو yarn

### خطوات التشغيل

1. **استنساخ المشروع**:

   ```bash
   git clone <repository-url>
   cd clothing-factory
   ```

2. **تثبيت التبعيات**:

   ```bash
   npm install
   ```

3. **تشغيل المشروع**:

   ```bash
   npm run dev
   ```

4. **فتح المتصفح**:
   - التطبيق: http://localhost:3000
   - API: http://localhost:3001

## 🔧 التطوير

### إضافة منتج جديد

1. أضف البيانات إلى `src/data/db.json`
2. استخدم API في `src/services/api.ts`
3. أضف المكونات في `src/pages/`

### إضافة صفحة جديدة

1. أنشئ المكون في `src/pages/`
2. أضف المسار في `src/App.tsx`
3. أضف الرابط في `src/components/Header.tsx`
